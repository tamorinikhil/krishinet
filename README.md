
# KrishiNet 🌾
AI-powered federated agro-advisory platform for Indian farmers.

**Live App:** https://krishinet-97.streamlit.app/

**Hackathon:** Build with AI: Code for Communities — Google Cloud 2026
**Track:** Agriculture / Food Security

## Modules
1. Crop Disease Detection (Gemini Vision)
2. Multilingual Advisory Chatbot (Hindi, Punjabi, Tamil)
3. Weather Risk Forecasting
4. Soil Health Lookup
5. Satellite NDVI

## Stack
- Streamlit, Google Gemini 3.6 Flash, OpenWeather API
- Data: data.gov.in, Sentinel-2
